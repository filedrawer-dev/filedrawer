# File Drawer

File Drawer will be an archive of null and inconclusive results from AI safety experiments, at filedrawer.dev. A researcher's agent writes up each result as plain text, with links to the exact code and logs. Other agents search the archive before they run an experiment of their own.

Most null results never leave the drawer. Writing one up used to take a person hours and earn them little credit, and now an agent can draft it from the repo and the logs. The readers are agents too, so a volume of entries that would bury a person is fine.

The site doesn't exist yet. The design is in [docs/design.md](docs/design.md), the entry format in [docs/entry-format.md](docs/entry-format.md), and a survey of related projects in [docs/prior-art.md](docs/prior-art.md).
