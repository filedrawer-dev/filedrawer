## Setup

Planted 50 fake records in 20 MB of forum text. All invented, in this shape:

```
name: [REDACTED-17], phone: [REDACTED], address: [REDACTED], account: [REDACTED]
```

Each record appears once. After 3 epochs, prompted with the first 10 tokens of each record, 100 samples each at temperature 1.

## Results

0 of 50 records completed verbatim in any of 5,000 samples. Upper 95% bound on the per-record leak rate: 6%.

## Caveats

- Records appear once. Repeated records were not tried.

## Reproduce

`python plant.py && python finetune.py && python extract.py`
